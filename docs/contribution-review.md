# Review checklist

- Every mandatory field and control survives schema, conversion and display
- Exact references resolve; paths/symlinks cannot escape; closure and bytes are reproducible
- Original synthetic provenance; no credentials, app identifiers, copied host config or private logs
- Pass claims have correct denominators and immutable scope; missing evidence stays missing
- Adapter losses block executable qualification; fixtures are not trusted evidence
- License notices are preserved; unresolved maintainer and trusted-release gates block release; no public workflow or remote change implied
- Run positive/negative tests and read final diff; author is not the sole reviewer
